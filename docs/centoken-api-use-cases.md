# Centoken API 使用场景说明

## 一句话理解

Centoken 提供统一的大模型 API 入口。只要一个应用支持自定义 OpenAI 风格的 API 地址、API Key 和模型名，通常就可以接入 Centoken 来使用 AI。

线上地址：<http://centoken.cn>

## 这类 API 可以用在哪些应用里

从使用方式上看，Centoken 更像一个通用 AI 能力接口层。它既可以给开发者调用，也可以配置到很多现成应用中使用。

通常只要应用支持以下任意一种能力，就有较大概率可以接入：

- 自定义 OpenAI API Base URL
- 自定义 API Key
- 自定义模型名称
- 兼容 OpenAI Chat Completions 或 Responses 接口

大多数情况下，你只需要配置三项内容：

- Base URL：`http://centoken.cn`
- API Key：你在 Centoken 控制台获取的密钥
- Model：你要使用的模型名称

## 常见使用场景

### 1. AI 聊天客户端

这类应用最适合普通用户和轻量使用场景。你可以把 Centoken 配置进去，直接获得统一的聊天、问答、写作、翻译和总结能力。

常见应用类型：

- 桌面 AI 客户端
- 浏览器中的对话工具
- 移动端聊天应用
- 多模型聚合聊天工具

适合做什么：

- 日常问答
- 文案润色
- 文章摘要
- 翻译改写
- 代码解释
- 方案草拟

常见可接入的产品方向示例：

- 支持自定义 OpenAI 地址的聊天客户端
- 支持第三方模型配置的 AI 对话工具
- 支持多模型切换的聚合型助手应用

### 2. 知识库与问答系统

如果一个应用支持把文档、网页、笔记或业务资料喂给大模型进行问答，那么通常也可以把底层模型接口替换为 Centoken。

适合做什么：

- 企业知识库问答
- 内部 SOP 查询
- 产品文档问答
- 客服知识辅助
- 教学资料检索问答

典型应用类型：

- RAG 知识库平台
- 企业内部智能问答系统
- 文档检索与总结工具
- FAQ 自动回答系统

这类系统一般会要求配置：

- 对话模型
- 向量模型或 Embedding 模型
- 重排模型或 Rerank 模型

Centoken 的价值在于，你可以把这些模型能力统一接在一个入口下管理。

### 3. 开发者工具和 IDE 插件

很多开发工具、编辑器插件和编程助手支持填写 OpenAI 接口地址。只要该工具允许自定义 Base URL，就可以尝试接入 Centoken。

适合做什么：

- 代码补全
- 代码解释
- Bug 排查建议
- 单元测试生成
- SQL、正则、脚本生成
- 技术文档辅助编写

典型应用类型：

- 编辑器 AI 插件
- IDE 编程助手
- 命令行 AI 工具
- 面向研发团队的代码问答系统

使用这类工具时，通常要特别注意模型是否支持：

- 长上下文
- 代码生成
- 工具调用
- 流式输出

### 4. 网站、后台系统和自研应用

如果你正在开发自己的网站、管理后台、小程序、APP 或 SaaS 产品，Centoken 可以作为统一的 AI 接口层接入后端服务。

适合做什么：

- 智能客服
- 内容生成
- 标题摘要提取
- 商品描述生成
- 邮件或消息拟写
- 数据分析解释
- 表单自动填写建议
- 企业内部助手

典型接入方式：

- Web 后端通过 HTTP 调用 Centoken API
- 移动端由服务端统一转发调用
- SaaS 平台在服务层接入模型能力
- 内部管理系统按模块接入不同模型

这也是最常见、最稳定的生产用法。

### 5. 自动化工作流平台

很多自动化平台、流程编排工具和低代码平台允许通过 HTTP 请求、OpenAI 节点或自定义 AI 节点接入模型接口。这类平台通常也可以接入 Centoken。

适合做什么：

- 自动总结表单内容
- 自动分类工单
- 自动回复邮件或消息
- 定时生成日报、周报
- 数据清洗与文本处理
- 多步骤 AI 审核流程

典型应用类型：

- 工作流编排平台
- 自动化机器人平台
- 低代码业务流程系统
- 表单触发型 AI 处理平台

如果平台内置的是 OpenAI 节点，通常只需要看它是否允许修改 Base URL。

### 6. 办公与内容创作工具

很多笔记工具、写作工具、文档系统和办公协同产品，支持接入自定义 AI 服务或通过插件方式连接大模型。这类工具也很适合使用 Centoken。

适合做什么：

- 会议纪要整理
- 文章润色
- 长文总结
- 标题生成
- 营销文案生成
- 多语言翻译
- 报告结构化整理

典型应用类型：

- 写作辅助工具
- 在线文档协作平台
- 笔记和知识管理工具
- 内容运营后台

### 7. AI 绘图、音频和多模态应用

如果某些应用支持图像生成、语音合成、语音转文本或其他多模态接口，并允许填写兼容接口地址，也可以通过 Centoken 统一接入。

适合做什么：

- 文生图
- 图片编辑
- 语音转文字
- 文本转语音
- 多模态内容生成

典型应用类型：

- AI 绘图工具
- 语音助手
- 配音工具
- 多媒体内容生产平台

在这类场景中，需要关注应用支持的具体接口路径，例如：

- `/v1/images/generations`
- `/v1/audio/speech`
- `/v1/audio/transcriptions`

### 8. 机器人与消息平台

如果你想把 AI 接到聊天机器人、企业 IM、社群机器人或客服消息系统里，也可以通过 Centoken 作为统一中间层。

适合做什么：

- 社群自动问答
- 企业 IM 助手
- 工单初步回复
- FAQ 自动应答
- 运营消息生成

典型应用类型：

- Telegram Bot
- Discord Bot
- 企业微信机器人
- 飞书机器人
- 网站在线客服系统

这类场景一般由你自己的服务端接入 Centoken，再把结果回传给聊天平台。

## 在哪些应用里通常可以配置这个 API

如果一个应用的“模型设置”页面中出现以下任意字段，一般就可以尝试配置 Centoken：

- OpenAI API Key
- OpenAI Base URL
- API Host
- API Endpoint
- Custom Provider
- Model Name

你可以优先关注以下几类应用：

- 支持 OpenAI 兼容接口的 AI 客户端
- 支持自定义模型服务的知识库系统
- 支持自定义 Provider 的工作流平台
- 支持填写 Base URL 的开发工具或插件
- 支持自定义 LLM 配置的聊天或办公软件

判断是否能接入，最简单的方法就是看它是否支持：

- 自定义接口地址
- 自定义密钥
- 自定义模型名称

如果三项都支持，通常就能接。

## 配置时一般怎么填

以大多数兼容 OpenAI 的应用为例，通常这样填写：

- API Base URL：`http://centoken.cn`
- API Key：控制台生成的密钥
- Chat Model：例如 `deepseek-v4-flash`

如果应用要求填写完整接口地址，再根据功能补充具体路径，例如：

- 聊天：`http://centoken.cn/v1/chat/completions`
- Responses：`http://centoken.cn/v1/responses`
- 向量：`http://centoken.cn/v1/embeddings`
- 图像：`http://centoken.cn/v1/images/generations`

## 最适合优先接入的应用

如果你第一次使用 Centoken，建议优先从以下三类应用开始：

### 1. 聊天客户端

配置最简单，最容易验证是否可用。

### 2. 自己的后端服务

最稳定、可控，适合正式业务接入。

### 3. 知识库或工作流工具

最容易快速体现 AI 的实际价值。

## 接入前的建议

- 先确认应用是否支持 OpenAI 兼容接口
- 先确认是否可以自定义 Base URL
- 先使用一个便宜且稳定的模型做联调测试
- 如果接入生产环境，建议由服务端统一调用，不要在前端暴露密钥
- 根据场景选择不同模型，不要把所有需求都压到同一个模型上

## 总结

Centoken API 的适用范围很广。凡是支持自定义 OpenAI 风格接口的聊天客户端、知识库系统、IDE 插件、网站后台、自动化平台、办公工具和机器人系统，通常都可以接入 Centoken 来使用 AI。

你可以把它理解成一个统一的 AI 能力底座。上层无论是聊天、写作、知识问答、代码辅助，还是自动化流程，只要能接 OpenAI 兼容接口，就有机会直接接入 Centoken。
