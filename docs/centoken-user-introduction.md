# Centoken 项目介绍

## 一句话说明

Centoken 是一个面向用户提供服务的统一大模型接口网关。它把不同厂商、不同协议的大模型能力整合到一个入口中，让你可以用更低的接入成本使用聊天、推理、向量、图像、音频等 AI 能力。

线上地址：<http://centoken.cn>

## Centoken 能为你解决什么问题

如果你正在使用多个 AI 模型或准备把 AI 能力接入自己的系统，通常会遇到这些问题：

- 不同模型供应商的接口格式不一致
- 切换模型时需要重复改代码
- 难以统一管理密钥、额度、计费和调用记录
- 团队多人使用时缺少可视化控制台
- 很难快速比较不同模型的价格和可用性

Centoken 的核心价值，就是把这些复杂度尽量收敛到一个统一入口里。你只需要面向一个平台接入，就可以更方便地管理和调用多种模型服务。

## 适合哪些用户

Centoken 适合以下几类用户：

- 个人开发者：希望快速调用大模型接口，不想分别适配多个平台
- AI 应用开发者：需要稳定的统一接入层，降低后续切换模型的成本
- 团队或工作室：需要统一管理成员使用额度、令牌和模型权限
- 企业内部项目：需要可视化控制台、用量统计和成本管理能力
- API 使用者：希望通过兼容 OpenAI 风格的方式快速接入现有应用

## 核心能力

### 1. 统一接入

Centoken 提供统一的接口入口，用户不需要分别对接多个模型厂商。对于很多现有应用来说，只需要将 API Base URL 替换为 Centoken 的地址，并使用平台提供的密钥，即可完成接入。

### 2. 多模型支持

平台支持接入多种主流模型与供应商能力，可覆盖聊天、推理、嵌入、重排、图像和音频等常见场景。用户可以在模型广场中查看当前可用模型、供应商、价格和计费方式。

模型广场：<http://centoken.cn/pricing>

### 3. OpenAI 兼容使用方式

对于已经兼容 OpenAI 接口格式的客户端、脚本或应用，迁移成本通常较低。你可以继续保留原有调用方式，只需将接口地址改为 Centoken，并替换为平台分配的密钥。

### 4. 可视化控制台

Centoken 提供用户控制台，用于完成账号登录、查看令牌、管理调用信息、了解可用模型和查看相关使用数据。

控制台入口：<http://centoken.cn/login>

### 5. 模型价格透明

在模型广场中，用户可以查看当前模型的输入价格、补全价格、计费类型、分组等信息，便于在性能、效果和成本之间做选择。

### 6. 面向实际业务的统一网关能力

Centoken 不只是一个简单的模型列表页，它更适合作为 AI 应用的统一能力入口。无论你是做聊天问答、内容生成、知识库、图像处理，还是企业内部自动化场景，都可以通过统一入口来完成模型接入和后续扩展。

## 用户可以如何开始使用

### 第一步：注册或登录

访问平台首页或登录页，完成注册与登录。

- 首页：<http://centoken.cn>
- 登录：<http://centoken.cn/login>
- 注册：<http://centoken.cn/register>

### 第二步：进入控制台获取密钥

登录后，进入控制台查看或创建可用令牌。后续通过 API 调用模型时，需要使用该密钥进行身份认证。

控制台：<http://centoken.cn/console>

### 第三步：选择模型

进入模型广场，查看当前可用模型、对应供应商和计费方式，确认你要调用的模型名称。

### 第四步：发起接口调用

如果你的应用已经支持 OpenAI 风格接口，可以直接将基础地址替换为：

```text
http://centoken.cn
```

常见接口路径示例：

- `/v1/chat/completions`
- `/v1/responses`
- `/v1/embeddings`
- `/v1/images/generations`
- `/v1/audio/speech`

一个最常见的聊天请求示例如下：

```bash
curl http://centoken.cn/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer 你的密钥" \
  -d '{
    "model": "deepseek-v4-flash",
    "messages": [
      {"role": "user", "content": "请简单介绍一下 Centoken。"}
    ]
  }'
```

如果你使用的是现成客户端、插件或第三方工具，通常只需要填写以下信息：

- Base URL：`http://centoken.cn`
- API Key：你在控制台获取的密钥
- Model：你在模型广场中选择的模型名称

## 典型使用场景

### AI 应用快速接入

如果你正在开发聊天助手、内容生成工具、客服系统或知识问答产品，Centoken 可以作为统一接入层，帮助你快速上线。

### 多模型测试与切换

你可以在同一平台下尝试不同模型，对比效果、速度与价格，找到更适合当前业务的方案。

### 团队共享与统一管理

对于多人协作场景，平台更适合统一管理令牌、模型权限和使用成本，降低成员分别管理多个供应商账号的复杂度。

### 业务系统 API 化接入

如果你希望把 AI 能力集成到网站、后台系统、自动化流程或内部工具中，Centoken 可以作为标准化接口层使用，便于后续扩展更多模型或供应商。

## 为什么选择 Centoken

- 接入简单：对很多已有应用来说，只需要修改基础地址和密钥
- 降低切换成本：后续更换模型时，不必大幅重写业务逻辑
- 使用更直观：通过控制台和模型广场查看模型、价格和接入信息
- 更适合持续运营：支持统一管理模型资源、调用能力和用户使用行为
- 扩展性更好：可以随着业务发展逐步增加模型种类和使用场景

## 使用建议

- 首次使用时，先在模型广场确认模型名称和计费信息
- 正式接入前，先用小流量进行功能测试和结果验证
- 妥善保管你的 API Key，不要泄露到前端页面或公开仓库
- 如果用于生产业务，建议做好错误重试、超时控制和额度监控

## 注意事项

- Centoken 提供的是统一接入与管理能力，具体模型效果仍取决于所选模型本身
- 不同模型的价格、速率和可用能力可能不同，请以模型广场展示信息为准
- 使用平台时，应遵守相关法律法规以及对应模型供应商的服务条款
- 如果后续启用了 HTTPS 域名，建议优先使用 HTTPS 地址进行生产接入

## 总结

Centoken 面向的不是单一模型，而是完整的 AI 接入体验。它帮助用户用统一方式连接多种模型能力，降低接入门槛，提升切换效率，并通过控制台和模型广场把使用、选择和管理过程变得更清晰。

如果你希望更快地把大模型能力接入自己的产品、脚本或业务系统，Centoken 是一个直接、实用且便于扩展的统一入口。
